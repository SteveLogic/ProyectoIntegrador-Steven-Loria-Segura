Registrar especialidad médica

Los datos se registrarán en MongoDB mediante POST /api/especialidades.

Editar especialidad médica

Las modificaciones se guardan mediante PUT /api/especialidades/:id. El estado no puede modificarse desde este formulario.

La API permite desactivar pero no reactivar una especialidad. El estado es solo informativo aquí.

Registrar usuario

La cuenta se guardará mediante POST /api/usuarios. La contraseña se envía al backend para almacenarse como hash; no aparecerá en la tabla ni en mensajes de confirmación. Trabajar solo en entorno local hasta implementar autorización del servidor.

Mínimo 8 caracteres. Se almacena como hash en MongoDB; no compartas contraseñas de cuentas reales.

Editar usuario

Se guardarán el nombre y el correo mediante PUT /api/usuarios/:id. El rol y la contraseña no se modifican desde este formulario.

El endpoint actual no permite cambiar roles.

Registrar perfil médico

Formulario diseñado para POST /api/doctores. Registre un perfil médico seleccionando un usuario con rol doctor y una especialidad activa. La información se guardará en MongoDB.

Editar perfil médico

Los cambios de colegiado y teléfono se guardan con PUT /api/doctores/:id; la especialidad se cambia mediante PUT /api/doctores/:id/especialidad. El nombre y correo pertenecen al usuario y son de solo lectura. La información se guardará en MongoDB.

Cambiar estado (demostración)

Solo cambia el estado de esta tabla temporalmente. La API actual permite DELETE /api/doctores/:id para desactivar, pero no tiene endpoint de reactivación; no se modifica disponibilidad de citas.

Nueva cita médica

Registro de cita en MongoDB mediante POST /api/citas. Elige doctor y fecha para consultar franjas libres de 30 minutos. La API valida la disponibilidad.

Reprogramar cita médica

Actualiza la cita mediante PUT /api/citas/:id. La API valida las fechas y rechaza horarios ocupados.

Se muestran franjas libres. La API verifica nuevamente al guardar.

Cancelar cita médica

Cita seleccionada:

Esta acción cambia el estado de la cita a Cancelada en MongoDB mediante DELETE /api/citas/:id. No se elimina físicamente.
